# 多功能桌面工具箱

集成常用小功能，一站搞定日常杂活。

## 核心功能

- **身份证号查询**：输入 18 位号码，解析出生日期、性别、年龄、户籍地并校验校验码
- **老黄历**：查农历日期、干支生肖、宜忌、吉神凶煞、冲煞方位
- **语录文案**：朋友圈文案、励志古言、毒鸡汤、土味情话、神回复、每日一句、诗词唐诗、脑筋急转弯等随机获取

## 文件工具

- **编码加密**：Base64 / Base32 / Hex、MD5 / SHA、AES / SM4、文件转 Base64
- **Office 处理**：PDF 合并拆分、图片转 PDF、提取文字、转图片、转 Word；Excel 合并、拆分工作表、按列去重、批量重命名列
- **文件时间修改**：批量改创建 / 访问 / 修改时间，设置只读 / 隐藏属性
- **压缩包解密**：对加密 zip / rar 尝试口令破解

## 系统工具

- **Windows 优化**：常用系统设置与 Win11 专属功能
- **酷狗音乐定时**：定时启动 / 关闭并自动播放
- **Zepp 运动刷步**：Zepp / 小米运动多账号批量刷步

## 媒体与生活

- **视频在线解析**：解析视频平台真实播放地址
- **U 盘文件拷贝**：插入 U 盘自动拷贝视频 / 图片
- **天气预报**：查城市天气与未来预报
- **菜谱搜索**：按关键词搜菜谱看详细教程

## 设置

- 启动设置、功能启用、接口密钥
- 默认输出目录、外观主题与字体
- 定时开关机、日志目录

> 说明：压缩包解密、视频解析、运动刷步等功能仅供学习研究使用。
> 打包成exe文件：在本目录下输入cmd回车，输入pyinstaller main.spec回车等待
